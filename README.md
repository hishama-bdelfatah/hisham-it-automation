# hisham-it-automation

Python automation scripts and tools for IT infrastructure, cybersecurity 
workflows, and AI data annotation tasks.

## About

Built by an IT infrastructure and cybersecurity professional (20+ years 
experience) working across multiple AI data annotation and evaluation 
platforms, specializing in Egyptian Arabic language tasks, speech-to-speech 
evaluation, and audio post-processing.

## Scripts

### `audio_file_organizer.py`
Validates audio filenames against annotation naming conventions 
(e.g. `YYMMDD_freetalk_secN_NNN_Speaker.wav`) and generates CSV templates 
for annotation deliverables.

**Usage:**
```bash
python audio_file_organizer.py
```
Then enter the folder path when prompted, and the output CSV filename.

## Requirements
- Python 3.x
- No external libraries required (uses built-in `os`, `re`, `csv` modules)
